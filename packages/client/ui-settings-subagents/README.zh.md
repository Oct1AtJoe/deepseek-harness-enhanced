# @deepseek-ai/dsh-client-ui-settings-subagents

[English](README.md) | 中文

Web 设置「插件」分区中的子智能体管理标签页。浏览器插件注册一个 id 为 `subagents` 的本地化 `settings.plugins.tab` 贡献；「插件」分区拥有导航入口与标签栏。标签页读取标准会话快照——列表零 RPC：它将每个父会话的 `subagentsByParent` 目录扁平化为跨会话名册，运行中优先排序，带模式标签（可继续 / 一次性）、父会话 id 与活动状态点。

每个健康子项提供「打开」操作（`sessions.openSubagent`），并且仅对运行中的可继续子项提供「停止」操作——经由连接的 `subagents.interrupt`、在持久父地址权限下路由，与输入框自身的停止语义一致；拒绝在行内呈现。标签页为会话摘要声称拥有子智能体子项的每个父会话自动拉取一次目录，「刷新」按钮重新拉取所有已知目录。文案中英双语，跟随当前语言。

## 模型体验

无：本包只渲染管理界面，不发起自己的模型提示词、工具、消息或 provider 请求。「停止」即输入框提供的同一人工发起中断，其持久效果由 Host 记录。

#### KV 缓存影响

无；本包从不组装模型输入。

## 已知限制与待办

- **不取消一次性子智能体** — 运行中的一次性子项按设计不可中断；只有可继续子项暴露「停止」。
- **名册仅实时状态** — 父会话已知时，已结束的子智能体仍保留在列表中；此处不提供历史视图或转写搜索（「打开」进入子项自己的会话）。
