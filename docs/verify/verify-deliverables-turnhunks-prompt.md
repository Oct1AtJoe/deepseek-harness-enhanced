# 验证产物面板本轮/累计分离

把以下内容复制到新对话的输入框，发送后观察产物面板。

---

## 第一轮：创建文件

请创建文件 `test-counter.txt`，内容写三行：
```
line 1
line 2
line 3
```

## 第二轮：追加内容

请在 `test-counter.txt` 末尾追加一行 `line 4`

## 第三轮：修改内容

请把 `test-counter.txt` 中的 `line 2` 改为 `line two`

## 预期效果

观察每轮结束后的产物面板：

| 轮次 | Chip badge | 展开面板 |
|------|-----------|---------|
| 第一轮 | `+3 -0` | 创建 3 行 |
| 第二轮 | `+4 -0`（累计）| 只显示追加的 `+line 4`（本轮 1 行）|
| 第三轮 | `+5 -1`（累计）| 只显示改的那一行（本轮 +1 -1）|
